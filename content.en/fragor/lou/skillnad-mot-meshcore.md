In three ways, all additions:

- **Auto-reply.** The repeater answers `test` in the county's test channel with a signal report,
  so anyone can see which repeaters they reach.
- **Remote control.** The owner changes settings without travelling to the repeater, with
  commands signed by the owner's own key.
- **Signed updates.** A repeater with Wi-Fi fetches new firmware itself, checks the signature and
  returns to the old image if the new one does not work.

Radio, routing, regions, the app and the admin password work as in ordinary MeshCore.
