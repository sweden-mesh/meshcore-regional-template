Observer is agessaman's firmware that lets a repeater with Wi-Fi report what it hears to the
map. lou comes on two bases:

- **On Observer:** everything Observer does is still there and unchanged, and lou adds auto-reply,
  remote control and signed updates. If you already run an Observer repeater, nothing you have set
  up changes.
- **On ordinary MeshCore:** for boards without Wi-Fi. These have auto-reply and remote control over the
  mesh, but no reporting to the map.

See [The map and observers](../../guider/visa-pa-kartan/).
