The variant is in the file name and in what `ver` answers.

| Code | Contents | Choose it if |
|---|---|---|
| `ar` | auto-reply | you want the repeater to be testable, but manage it on site or with the admin password |
| `rc` | remote control | you want to change settings remotely, and the county already has enough repeaters answering `test` |
| `arrc` | both | you are unsure. Both are off until you turn them on |

A repeater with Wi-Fi takes the Observer variant, so that it also shows on the map.
