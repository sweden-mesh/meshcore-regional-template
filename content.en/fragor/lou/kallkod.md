At [github.com/sweden-mesh/MeshCore-lou](https://github.com/sweden-mesh/MeshCore-lou/releases). Every release lists all its files and
what changed. The file name says what the file is, for example
`...-esp32s3-v1.18.0-lou-18-arrc-...`: the chip, the MeshCore version, the lou version and the
variant.

A new version is released at most once a month, so that the mesh does not have to be re-flashed
needlessly.
