In lou-18 a command to a single repeater, and its answer, is encrypted between you and the
repeater. The server sees which repeater the command is for and which region it belongs to, but
not what it says. A command to every repeater in a region is signed but readable.

In lou-20, which is built but not released, no region is left in remote control and there is no
command to all at once. Everything is encrypted to the owner, and the server cannot see which
repeaters have the same owner.
