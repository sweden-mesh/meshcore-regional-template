# When the template is 1.0

Until 1.0, minor versions may still change params in ways that need a region to edit its
`hugo.toml` (noted under "Breaking" in `CHANGELOG.md`). 1.0 promises that only a major version
does that. It is reached when all of these hold:

**Proven in use**
- [x] One region in production on it (meshcore-jkp.se, since v0.1.0).
- [ ] A **second region** has started a site from `exampleSite/` using only the README, and its
      questions are answered in the docs.
- [ ] The wizards have **applied settings to real repeaters** over Web Serial, on an ESP32 and an
      nRF52 board.

**Stable interfaces**
- [ ] The params (`region`, `map`, `beacon`, `radio`, `naming`, `channels`, `chats`, `analytics`,
      `firmware`, `observer`, `style`) unchanged through two minor releases.
- [ ] The override points documented and checked in CI: pages, partials, i18n keys, hooks, logo,
      CSS tokens (`scripts/check-overrides.sh` covers pages, partials and i18n today).
- [ ] The Beacon endpoints the map uses listed with the Beacon version they were tested against,
      and a check that fails when a new Beacon changes them.

**Quality**
- [x] Accessibility: axe-core WCAG 2 A/AA clean, light and dark, both styles.
- [x] Works without JavaScript for reading (node list, guides) and on a 390 px phone.
- [ ] Map performance measured on a real mid-range phone, not only a throttled desktop.
- [ ] An English i18n file, so regions outside Sweden can use it.

**Docs**
- [x] README covers settings, overriding, building, CI elsewhere (`CI.md`), releases, versions.
- [ ] A short "how the map works" page for maintainers (data flow, Beacon, snapshot, privacy).
