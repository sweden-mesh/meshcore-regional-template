Returns the valid places as "list" (note rendered as HTML, for the host wizard's list) and "json" (note as plain text, for the maps' data-wanted). No places: an empty list and an empty json string. */ -}} {{- $list := slice -}}{{- $plain := slice -}} {{- range site.Params.wanted -}} {{- if and .name (isset . "lat") (isset .
