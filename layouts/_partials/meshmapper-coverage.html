{{- /* The region's measured coverage from MeshMapper (coverage API, schema 2), fetched while the site builds. The key comes from the environment variable HUGO_MESHMAPPER_KEY and decides the region; it is sent only as the X-API-Key header and never written anywhere. Filters: the region's radio setting (params.radio, any coding rate) and the last params.meshmapper.days days. params.meshmapper.fixture reads a saved response from the site's assets instead (tests, the example site). Off unless params.meshmapper.coverage is true. No key and no fixture: no request and nothing returned. A failed request (HTTP error, success != true, no grid_squares) gives one warning and nothing; the build goes on. The cache key changes every 6 hours, so local rebuilds reuse one download (the key allows 100 calls a day). Accept-Encoding is left to Go, which then decompresses the gzip answer itself. Returns the parsed response plus at, newest and compact (a JSON string, below), or nil. */ -}} {{- $mm := site.Params.meshmapper | default dict -}} {{- $data := dict -}} {{- /* Only when the region has turned the layer on (params.meshmapper.coverage). */ -}} {{- if $mm.coverage -}} {{- with $mm.fixture -}} {{- with resources.Get . -}}{{- $data = .Content | transform.Unmarshal -}}{{- end -}} {{- else with getenv "HUGO_MESHMAPPER_KEY" -}} {{- $r := site.Params.radio -}} {{- $url := printf "https://meshmapper.net/coverage.php?f_freq=%v&f_bw=%v&f_sf=%v&f_days=%v" $r.freq $r.bw $r.sf ($mm.days | default 180) -}} {{- $slot := printf "%s-%d" (now.UTC.Format "20060102") (div now.UTC.Hour 6) -}} {{- $opts := dict "key" (printf "meshmapper-%s-%s-%s" (md5 .) (md5 $url) $slot) "headers" (dict "X-API-Key" . "Accept" "application/json") -}} {{- with try (resources.GetRemote $url $opts) -}} {{- with .Err -}} {{- warnidf "meshmapper" "MeshMapper coverage not fetched (%s); the map has no coverage layer" . -}} {{- else with .Value -}} {{- $data = .Content | transform.Unmarshal -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- if and $data (or (ne $data.success true) (not $data.grid_squares)) -}} {{- warnidf "meshmapper" "MeshMapper coverage unusable (success %v, error %q, %d squares); the map has no coverage layer" $data.success ($data.error | default "") (len ($data.grid_squares | default slice)) -}} {{- $data = dict -}} {{- end -}} {{- /* Freshness: when MeshMapper computed the answer (at) and the newest ping in it (newest), both in seconds; the API's timestamps above 2e10 are milliseconds. Nothing is kept between builds, so a revoked key means no layer from the next build on. The compact form for the browser (squares): [latIdx, lonIdx, kind, eff10, ageDays, type, pings] per square. latIdx/lonIdx come from grid_id ("latIndex_lonIndex"): south = latIdx × grid[0], west = lonIdx × grid[1]. kind "w" = working (BIDIR, DISC, TX, RX), "d" = dead (DEAD, DROP); eff10 = round(effective × 10); ageDays = UTC days from the square's newest ping to at, so at's day minus ageDays is the ping's date; type = index into types; pings = count. */ -}} {{- $out := dict -}} {{- if $data -}} {{- $types := slice "BIDIR" "DISC" "TX" "RX" "DEAD" "DROP" -}} {{- $at := $data.generated_at | default 0 -}} {{- $at = cond (gt $at 2e10) (div $at 1000) $at -}} {{- $atDay := math.Floor (div $at 86400.0) -}} {{- $newest := 0 -}} {{- $squares := slice -}} {{- range $data.grid_squares -}} {{- $t := .timestamp | default 0 -}} {{- $t = cond (gt $t 2e10) (div $t 1000) $t -}} {{- if gt $t $newest }}{{ $newest = $t }}{{ end -}} {{- $ix := split (.grid_id | default "") "_" -}} {{- $type := 0 -}}{{- $known := false -}} {{- $ct := .coverage_type -}} {{- range $i, $name := $types }}{{ if eq $name $ct }}{{ $type = $i }}{{ $known = true }}{{ end }}{{ end -}} {{- if and $known (eq (len $ix) 2) -}} {{- $squares = $squares | append (printf "[%d,%d,%q,%d,%d,%d,%d]" (int (index $ix 0)) (int (index $ix 1)) (cond (ge $type 4) "d" "w") (int (math.Round (mul (.effective | default 0) 10))) (int (sub $atDay (math.Floor (div $t 86400.0)))) $type (int (.count | default 0))) -}} {{- end -}} {{- end -}} {{- $grid := slice ($data.grid_size.lat | default 0) ($data.grid_size.lon | default 0) -}} {{- $head := dict "v" 1 "grid" $grid "at" (int $at) "newest" (int $newest) "types" $types | jsonify -}} {{- $compact := printf "%s,\"squares\":[%s]}" (strings.TrimSuffix "}" $head) (delimit $squares ",") -}} {{- $out = merge $data (dict "at" (int $at) "newest" (int $newest) "compact" $compact) -}} {{- end -}} {{- return (cond (gt (len $out) 0) $out nil) -}}
